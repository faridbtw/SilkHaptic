# Banner assets

`silkhaptic-banner.svg` contains the editable red banner layout. The README displays `silkhaptic-knight-hornet-banner.png` for consistent rendering on GitHub.

`dualsense-white.png` is Sony’s official **white DualSense** product artwork, used with its supplied transparent background. Source: [PlayStation DualSense product page](https://www.playstation.com/en-us/accessories/dualsense-wireless-controller/).

Direct image URL:

https://gmedia.playstation.com/is/image/SIEPDC/dualsense-controller-product-thumbnail-01-en-14sep21?fmt=png-alpha&wid=1000

Controller image © Sony Interactive Entertainment. The third-party product artwork is not covered by the repository’s MIT software license. Its inclusion identifies the supported controller; SilkHaptic is an independent community project.

## The Knight and Hornet

The banner uses Team Cherry’s official transparent character promotional artwork, with its original colors and transparency:

- `knight-official.png`: `char_knight.png` from the [Hollow Knight character press kit](https://drive.google.com/drive/folders/1edIKwseJidG4DtPUd5A3tcC9IEB6ccb-). [Original file](https://drive.google.com/file/d/1k3FSs12QYYDod-xGw_woI5KuqTOSMCUS/view).
- `hornet-official.png`: `hornet_large.png` from the [Silksong character press kit](https://drive.google.com/drive/folders/1gjCKkQww45JAWMvmUXsbODrr-90Jw7pP). [Original file](https://drive.google.com/file/d/1wf2gBtOZE-b7lIJzTtxmSdIeCWzJe-I8/view).

Both press kits are linked from the games’ official websites: [Hollow Knight](https://www.hollowknight.com/) and [Silksong](https://hollowknightsilksong.com/). Character artwork © Team Cherry. These promotional images identify the supported games and are not covered by this repository’s MIT software license.
